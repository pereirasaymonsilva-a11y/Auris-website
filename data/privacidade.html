Política de Privacidade

A privacidade dos usuários é uma parte importante do Auris. Esta página explica quais informações são utilizadas pelo aplicativo e como elas são tratadas.

Última atualização · Agosto de 2026
01

Coleta de dados

O Auris não coleta dados pessoais dos usuários para fins de rastreamento ou criação de perfis. O aplicativo não exige cadastro ou login para ser utilizado.

02

Permissões do aplicativo

O Auris pode solicitar permissões necessárias para acessar os arquivos de áudio armazenados no dispositivo. Essas permissões são utilizadas para localizar e reproduzir músicas disponíveis localmente.

03

Arquivos e músicas

Os arquivos de música encontrados no dispositivo são processados localmente pelo aplicativo. O Auris não envia automaticamente esses arquivos para servidores externos.

04

Dados de uso

O Auris não utiliza dados de uso para rastrear individualmente os usuários. Informações pessoais não são utilizadas para criar perfis de publicidade.

05

Compartilhamento de informações

O Auris não vende ou compartilha informações pessoais dos usuários com terceiros para fins comerciais.

06

Segurança

O processamento relacionado à reprodução e organização das músicas ocorre localmente sempre que possível. Recomendamos manter o Android e o aplicativo atualizados para obter as correções de segurança disponíveis.
